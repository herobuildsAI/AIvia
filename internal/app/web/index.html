IP intelligence
Choose where optional IP lookups go. Saving does not send a lookup.




Compatible endpoints accept the ipapi.is JSON format. Use public HTTPS on port 443, or an HTTP(S) literal loopback address for a local service. Private LAN endpoints are not supported.




Keys saved here are plaintext in your local data store and its backup. They are never returned to the browser or included in reports or model context. Changing the provider or endpoint drops the old key. AIVPN_IPAPI_KEY is a fallback for ipapi.is only; removing a saved key does not unset that environment variable.






Private, with clear boundaries
Profiles, notes, settings, saved IP keys, and explicitly saved redacted reports are stored as plaintext in the local data directory printed at startup. This app does not persist conversation history or raw network evidence.
External checks require a click. There is no application telemetry, account sync, or automatic policy refresh. CLI runtimes have their own data and telemetry policies.
Optional local HTTP model credentials are read from AIVPN_MODEL_TOKEN at startup. Credentials are never stored in service profiles.
