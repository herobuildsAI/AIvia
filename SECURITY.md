# Security

The application is a single-user local diagnostic and Career Radar tool. It binds only to loopback, checks Host/Origin and a per-process session token, restricts local HTTP model destinations to loopback, refuses redirects, and validates/pins public target destinations. Do not expose it through a tunnel, reverse proxy, shared host, or container port mapping.

The boundary protects against ordinary cross-origin websites, not malicious same-user processes, compromised browsers/extensions, or a dishonest local model runtime. Local HTTP is unencrypted; raw evidence and chat exist in process/browser memory. Notes, saved reports, Career evidence/student profiles/advice, and UI-saved IP/OpenRouter keys are plaintext on disk and may remain in backups. Version-1 migration preserves a separate original-byte backup; do not publish stores or backups. Career source content is untrusted and model guidance requires review; only explicitly selected context and an opted-in student profile are handed to the chosen assistant. The optional Claude CLI adapter is a separately consented trust boundary: model tools are disabled, but administrator hooks and policies may still apply. Codex receives no context automatically; its integration is manual clipboard handoff. Review exports before sharing.

GitHub private vulnerability reporting is enabled. Submit security reports through the [private reporting form](https://github.com/herobuildsAI/AIvia/security/advisories/new). If it is unavailable, open a minimal issue asking for a private channel without exploit details, credentials or personal data.

Build only with the latest security patch of a [supported Go branch](https://go.dev/doc/devel/release), at least Go 1.26.8 or Go 1.27.1 for those branches. Earlier patches are outside this distribution's security floor; rebuild affected binaries with a patched toolchain. CI runs pinned `govulncheck` v1.8.0 on Linux and fails when it detects reachable vulnerabilities. Keep the toolchain and scanner current when reviewing future advisories. This distribution contains source only. Distributors building binaries are responsible for applicable license notices, signing, and release provenance.
